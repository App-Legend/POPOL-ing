테스트를 실행하고 결과만 요약한다. 코드는 고치지 않는다.

## 실행
- 테스트 명령은 기술 스택 확정 전이라 미정이다. 확정되면 아래 `<테스트 명령>`을 바꾼다(Flutter라면 `flutter test`).
- 저장소 루트에서 `<테스트 명령>`
- 특정 파일만 요청받으면 `<테스트 명령> <파일 경로>`
- 테스트 명령이 아직 없으면 실행하지 말고 "테스트 명령 미정"이라고만 돌려준다.

## 돌려줄 내용
- 통과·실패 개수
- 실패마다: 테스트 이름, 기대값, 실제값, `파일:줄`
- 전체 로그는 붙이지 않는다.
