# 건우 작업 기록

## 2026-11-12

**완료**
- 하네스 마무리(`app/` 기능별 `register()` 조립 구조, 두 OS CI, PR 템플릿, `main` push 차단 훅) 및 macOS 프로세스 실행·로그·트리 종료 검증
- **결정:** macOS는 새 프로세스 그룹(`perl -e 'setpgrp(0,0); exec @ARGV'`)으로 실행하고, 종료는 그룹 전체에 TERM → 몇 초 뒤 KILL. 일반 `Process.kill()`은 손자 프로세스가 남고, Dart `detachedWithStdio`는 pgid≠pid라 종료 대상을 알 수 없다.
- **결정:** A 계약(`Orchestrator`·`RuntimeQuery`·`core/events`)은 1.0 태그 뒤 추가로 올린다. 1.0 뒤에도 새 계약 추가는 허용된다.
- **결정:** `AGENTS.md`는 만들지 않는다. 팀원 모두 Claude Code만 써서 `CLAUDE.md`로 충분하다.

**다음 할 일**

- 3주차: OS별 실행·종료, 로그 저장, 실행 기록·소유권, 전체 실행(의존 순서, 준비 조건, 실패 시 건너뜀)·전체 종료, 목요일 첫 조립
